# Держава

Симулятор экономики и государства для Android: конструктор страны, налоги, бюджет, ЦБ, регионы, выборы, внешний мир, кризисы и методички на четырёх уровнях сложности.

Игра — HTML/JS в `app/src/main/assets`, обёртка — WebView (`MainActivity`). Обновления приходят из релизов этого репозитория (`Updater`).

Выпуск версии: `./release.sh 1.2 "Что нового"`.
